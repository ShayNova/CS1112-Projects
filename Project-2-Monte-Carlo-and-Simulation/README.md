# Project 2 | Monte Carlo Methods & Numerical Simulation

## Overview

An exploration of computational simulation and numerical approximation using Python. This project applies random sampling and iterative algorithms to estimate geometric areas and model the behavior of an electrical system over time.

## Project Components

### 1. Monte Carlo Area Estimation
- Apply Monte Carlo simulation to approximate the difference in area between two mathematically defined heart-shaped regions.
- Generate random coordinate samples and classify points based on geometric boundaries.
- Visualize sampling distributions and estimated areas using Matplotlib.

### 2. Capacitor Voltage Simulation
- Model the charging behavior of a capacitor using mathematical equations and iterative calculations.
- Determine the approximate time required to reach a user-specified voltage.
- Incorporate input validation and conditional logic to evaluate whether a target voltage is achievable.

### 3. Indicator Light Duration Analysis
- Simulate capacitor charging and discharging to estimate how long an indicator light remains active.
- Analyze the relationship between charging time and the duration above a specified voltage threshold.
- Visualize simulation results and consider the computational efficiency of alternative iterative approaches.

## Technical Concepts

- Monte Carlo methods and random sampling
- Numerical approximation
- For-loops, while-loops, and nested iteration
- Simulation and mathematical modeling
- Input validation and conditional logic
- Algorithmic efficiency
- Data visualization with Matplotlib

## Technologies

**Language:** Python

**Libraries:** Matplotlib, random, math

## Key Takeaway

Demonstrates the use of Python to approximate mathematical quantities, simulate dynamic systems, and visualize computational results, establishing foundational skills relevant to scientific computing and data analysis.
