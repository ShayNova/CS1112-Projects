# Project 1 | Python Fundamentals & Mathematical Applications

## Overview

An introduction to Python programming through mathematical computation, conditional logic, and 
interactive visualization. This project explores how fundamental programming concepts can be 
applied to numerical approximation, practical calculations, and geometric modeling.

## Project Components

### 1. Cube Root Approximation
- Approximate cube roots using iterative averaging methods.
- Compare two numerical approximation techniques across successive iterations.
- Format and display results in structured tables to evaluate approximation behavior.

### 2. Book Order Pricing Calculator
- Calculate total order costs based on book prices, quantities, shipping fees, discounts, and taxes.
- Apply conditional logic to distinguish between bookstore and individual customer orders.
- Generate itemized billing summaries based on user-provided inputs.

### 3. Interactive Shadow Visualization
- Model the geometric relationship between a light source, rectangular object, and resulting shadow.
- Incorporate randomized light-source positioning and interactive user input.
- Use Matplotlib to visualize geometric relationships and shadow boundaries.

## Technical Concepts

- Python syntax and variables
- Conditional statements and Boolean expressions
- Mathematical computation and numerical approximation
- User input and formatted output
- Random number generation
- Scientific visualization with Matplotlib

## Technologies

**Language:** Python

**Environment:** Jupyter Notebook

**Libraries:** Matplotlib, random

## Key Takeaway

Demonstrates foundational Python programming skills through the application of mathematical 
reasoning, structured decision-making, and graphical representation of computational results.
