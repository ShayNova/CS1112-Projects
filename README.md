# CS 1112 | Science & Engineering Perspective

These projects explore the application of computational methods to mathematical modeling, numerical approximation, simulation, and scientific visualization. Through progressively complex programming challenges, the coursework emphasizes algorithm development, analytical reasoning, and the translation of mathematical concepts into computational solutions.

## Project Portfolio

### Project 1: Python Fundamentals & Mathematical Applications
**Focus:** Numerical Approximation, Conditional Logic, Scientific Visualization

Explores foundational Python programming through numerical approximation, conditional pricing calculations, and geometric modeling. Applications include cube root approximation, automated book-order billing, and interactive shadow visualization.

### Project 2: Monte Carlo Methods & Numerical Simulation
**Focus:** Random Sampling, Iterative Algorithms, Computational Modeling

Applies Monte Carlo methods to estimate geometric areas and uses iterative numerical simulations to model capacitor voltage and indicator-light behavior. Emphasizes approximation, computational efficiency, and graphical representation of results.

### Project 3: Sensitivity Analysis & Physics-Based Simulation
**Focus:** Parameter Analysis, Modular Programming, Scientific Computing

Investigates how changes in model parameters affect computational outcomes through capacitor voltage sensitivity analysis and simulations of colliding objects. Introduces modular program development, array operations, physical modeling, and scientific visualization.
