# Project 3 | Computational Modeling & Sensitivity Analysis

## Overview

An exploration of computational modeling, sensitivity analysis, and physics-based simulation using Python. This project investigates how variations in model parameters influence system behavior and applies modular programming techniques to simulate interactions between moving objects.

## Project Components

### 1. Capacitor Voltage Sensitivity Analysis
- Model capacitor voltage as a function of time during charging and discharging.
- Perform sensitivity analyses by systematically varying capacitance and charging time.
- Compare voltage trajectories across parameter configurations.
- Generate scientific visualizations to illustrate the relationship between model inputs and system behavior.

### 2. Colliding Blocks Simulation
- Simulate the motion of multiple rectangular blocks within a bounded environment.
- Update object positions and velocities across discrete time steps.
- Model collisions between blocks and boundaries using principles of motion and momentum.
- Extend the simulation to account for kinetic friction and inelastic collisions.
- Visualize how different physical conditions affect system behavior over time.

## Technical Concepts

- Sensitivity analysis and parameter variation
- Numerical simulation and discrete time steps
- Mathematical and physical modeling
- Modular programming and user-defined functions
- Lists and NumPy arrays
- Collision detection and state updates
- Computational approximation
- Scientific visualization with Matplotlib

## Technologies

**Language:** Python

**Libraries:** NumPy, Matplotlib, math

## Key Takeaway

Demonstrates the application of computational methods to model dynamic systems, evaluate parameter sensitivity, and visualize complex behavior. Emphasizes modular algorithm design, numerical reasoning, and simulation techniques relevant to scientific computing and quantitative analysis.
